## Aeminium Project - Curricula Knowledge Evaluator

This is the homepage for all the repositories of my personal project called Aeminium.

Aeminium is a backend service that serves the purpose of measuring how any given academic course fares against the different community-accepted Bodies of Knowledge.

This project is composed of multiples repositories that host software libraries, API services and some specialised artifacts like architecture diagrams or infrastructure definition.

For the technical documentation, please check [this Notion page](https://cmogoncalves.notion.site/Aeminium-0e21f43b2a944791828e15d5252ddc84)
